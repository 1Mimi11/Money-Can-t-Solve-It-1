I plan to create a fully functioning fishing game where you can fish, sell catches, and upgrade your rod and fishing methods. 
Right now it's still in it's early stages, but follow along as it gets better!

I created this project in Eclipse for Windows, using Java. It's fully runnable in a GitHub codespace browser, so there is no need to compile anything. 

To run the code, use the demo link and click the run button in the code space environment. The code will pop up in the terminal, where you can use keyboard controls to play.
